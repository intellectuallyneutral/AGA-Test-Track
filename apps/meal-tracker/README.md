# 🍽️ Isabelle's Meal & Symptom Tracker

A dead-simple, family-friendly web app for tracking food, drinks, and acid reflux symptoms. Designed for non-tech-savvy family members — just tap a link, fill in the form, and submit.

## Features

- **One-tap food/drink logging** — no login, no account
- **Symptom tracking** with severity levels (mild/moderate/severe)
- **Auto-timezone** — all entries converted to Eastern Time regardless of submitter's location
- **Backlog support** — change date/time for past entries
- **Admin dashboard** — password-protected, dark-themed, professional
- **Symptom ↔ meal correlation** — automatically links symptoms to meals within 8 hours
- **PDF export** — generate clean reports for Isabelle's doctor
- **100% free** — Supabase free tier + GitHub Pages

## Tech Stack

- Pure HTML/CSS/JS (no framework, instant load on mobile)
- Supabase PostgreSQL (free tier)
- GitHub Pages hosting (free)
